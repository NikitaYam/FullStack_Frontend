# FullStack_Frontend
Разработка пользовательского интерфейса по предмету "Разработка полного цикла"

«Читатель» — приложение для любителей книг: каталог и книжная полка, читалка, дневник чтения с заметками, лента читателей с отзывами и комментариями, личные чаты и ИИ-ассистент для подбора книг.

**Стек:** React 19, TypeScript, Vite, MUI (Material UI), React Router.

## Запуск

Нужен Node.js 20.19+ или 22.12+ (требование Vite 8).

```bash
npm install
npm run dev        # dev-сервер: http://127.0.0.1:5173
npm run build      # проверка типов и production-сборка
npm run lint       # ESLint
```

Необязательная переменная окружения (файл `.env.local`, в репозиторий не попадает):

| Переменная | Значение |
|---|---|
| `VITE_MOCK_ERROR_RATE` | доля демо-запросов, завершающихся ошибкой, от `0` до `1` (по умолчанию `0`). Нужна, чтобы проверить состояния ошибок |

## Архитектура (ЛР №3)

Используется упрощённый Feature-Sliced Design. Слои сверху вниз, каждый импортирует только из нижележащих:

| Слой | Назначение | Примеры |
|---|---|---|
| `app` | настройка приложения: провайдеры, маршруты, каркас страниц | `App.tsx`, `router.tsx`, `layout/AppLayout.tsx` |
| `pages` | экраны: собирают интерфейс из фич и сущностей | `BookPage`, `SocialPage` |
| `features` | действия пользователя: формы, лайк, фильтр | `review-create`, `post-like`, `book-filter`, `auth` |
| `entities` | данные предметной области: типы, API, карточки | `book`, `user`, `post`, `review`, `diary`, `chat` |
| `shared` | общие компоненты и утилиты без знания о предметной области | `useAsync`, `useForm`, `AsyncView`, `routes` |

```
src/
├── main.tsx
├── app/          App, router, theme, layout
├── pages/        страницы
├── features/     auth, account-settings, book-filter, comment-create, diary-entry-edit,
│                 diary-log, post-create, post-like, reader-settings, recommendations,
│                 review-create, send-message
├── entities/     book, chat, diary, post, review, user  (model/ — типы, api/, ui/)
├── shared/       api/ (mockRequest), config/ (routes), lib/ (хуки, валидаторы), ui/
└── mocks/db.ts   демо-данные
```

Модуль импортируется снаружи только через свой `index.ts` (публичный API); алиас `@/` указывает на `src/`.

Отступления от FSD: нет слоя `widgets` (крупных повторяющихся блоков пока нет); сущности могут ссылаться на типы друг друга (например, `Review.author: UserBrief`).

### Данные
До подключения API (ЛР №5) данные берутся из `src/mocks/db.ts` через функции `entities/*/api`. Они асинхронные и имитируют сеть (`shared/api/mockRequest.ts`): задержка 300–800 мс и случайные ошибки с вероятностью `VITE_MOCK_ERROR_RATE`. Записи хранятся «как в БД» (связи по id), а API сущностей собирает из них ответы — как это будет делать бэкенд. Изменения живут в памяти до перезагрузки страницы. При интеграции с FastAPI заменяется только реализация функций `entities/*/api`.

### Динамический интерфейс
- **Состояния данных.** На всех экранах с данными — загрузка (индикатор или скелетоны), ошибка с кнопкой «Повторить», пустое состояние с подсказкой. Реализовано единым компонентом `shared/ui/AsyncView` и хуком `shared/lib/useAsync`.
- **Формы и валидация** (`shared/lib/useForm`): вход/регистрация, отзыв, статус книги и заметки дневника, пост, комментарий, сообщение, настройки. Ошибка поля показывается после ухода с поля или попытки отправки; ошибки сервера — над кнопкой отправки; кнопки сохранения активны только при изменениях.
- **Анимации:** плавная смена страниц, раскрытие формы отзыва и полей регистрации, появление и удаление элементов списков, «пульс» лайка, перелистывание глав, индикатор «ассистент печатает».
